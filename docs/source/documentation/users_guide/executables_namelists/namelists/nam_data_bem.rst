* :code:`NPAR_FLOOR_LAYER` : number of layers in roofs

* :code:`NPAR_MASS_LAYER` : number of layers for the internal mass in input data. This does NOT refer to the computational grid. The mass properties are interpolated from the input grid to the computational grid.

* :code:`XPAR_CF_CO2_ELEC` : Emission factor CO$_{2}$/electricity (KgCO$_{2}$.J$^{-1}$)

* :code:`XPAR_CF_CO2_GAS` : Emission factor CO$_{2}$/gas (KgCO$_{2}$.J$^{-1}$)

* :code:`XPAR_CF_CO2_FUEL` : Emission factor CO$_{2}$/fuel (KgCO$_{2}$.J$^{-1}$)

* :code:`XPAR_CF_CO2_OTHER` : Emission factor CO$_{2}$/other sources. The defaults emission factor assumes wood. (KgCO$_{2}$.J$^{-1}$)

* :code:`XUNIF_HC_FLOOR / CFNAM_HC_FLOOR / CFTYP_HC_FLOOR` : heat capacity of floor layers (J m$^{-3}$ K$^{-1}$)

* :code:`XUNIF_TC_FLOOR / CFNAM_TC_FLOOR / CFTYP_TC_FLOOR` : thermal conductivity of floor layers (W m$^{-1}$ K$^{-1}$)

* :code:`XUNIF_D_FLOOR / CFNAM_D_FLOOR / CFTYP_D_FLOOR` : thickness of floor layers (m)

* :code:`XUNIF_HC_MASS / CFNAM_HC_MASS / CFTYP_HC_MASS` : heat capacity of up to 9 mass layers (J/K/m$^{3}$)

* :code:`XUNIF_TC_MASS / CFNAM_TC_MASS / CFTYP_TC_MASS` : thermal conductivity of up to 9 mass layers (W/m/K)

* :code:`XUNIF_D_MASS / CFNAM_D_MASS / CFTYP_D_MASS` : depth of up to 9 mass layers (m)

* :code:`XUNIF_FLOOR_HEIGHT / CFNAM_FLOOR_HEIGHT / CFTYP_FLOOR_HEIGHT` : building floor height (m)

* :code:`XUNIF_F_WASTE_CAN / CFNAM_F_WASTE_CAN / CFTYP_F_WASTE_CAN` : fraction of waste heat into the canyon

* :code:`XUNIF_F_WATER_COND / CFNAM_F_WATER_COND / CFTYP_F_WATER_COND` : fraction of evaporation for condensers

* :code:`XUNIF_DCS_AREA / CFNAM_DCS_AREA / CFTYP_DCS_AREA` : presence of district cooling system

* :code:`XUNIF_HR_TARGET / CFNAM_HR_TARGET / CFTYP_HR_TARGET` : relative humidity setpoint

* :code:`XUNIF_QIN / CFNAM_QIN / CFTYP_QIN` : internal heat release (W m$^{-2}$). This value can be specified for up to 9 tiles of use/behaviour.

* :code:`XUNIF_QIN_FRAD / CFNAM_QIN_FRAD / CFTYP_QIN_FRAD` : radiant fraction of internal heat gains

* :code:`XUNIF_QIN_FLAT / CFNAM_QIN_FLAT / CFTYP_QIN_FLAT` : latent fraction of internal heat gains

* :code:`XUNIF_MODQIN_VCD / CFNAM_MODQIN_VCD / CFTYP_MODQIN_VCD` : Modulation factor for internal heat release when the building is vacant for short duration. This value can be specified for up to 9 tiles of use/behaviour (NBEMCOMP)

* :code:`XUNIF_MODQIN_VLD  / CFNAM_MODQIN_VLD  / CFTYP_MODQIN_VLD` : Modulation factor for internal heat release when the building is vacant for long duration (e.g. holidays). Can be specified for up to 9 tiles of use/behaviour (NBEMCOMP)

* :code:`XUNIF_MODQIN_NIG / CFNAM_MODQIN_NIG / CFTYP_MODQIN_NIG` : Modulation factor for internal heat release during the night. This value can be specified for up to 9 tiles of use/behaviour (NBEMCOMP)

* :code:`XUNIF_SHGC / CFNAM_SHGC / CFTYP_SHGC` : solar transmitance of windows (1)

* :code:`XUNIF_U_WIN / CFNAM_U_WIN / CFTYP_U_WIN` : U-Value of window (W.m$^{-2}$.K$^{-1}$)

* :code:`XUNIF_GR / CFNAM_GR / CFTYP_GR` : glazing ratio (1)

* :code:`XUNIF_SHGC_SH / CFNAM_SHGC_SH / CFTYP_SHGC_SH` : solar transmitance of windows + shading

* :code:`XUNIF_N50 / CFNAM_N50 / CFTYP_N50` : Airtightness of the building (vol/h at 5O Pa)

* :code:`XUNIF_CAP_SYS_HEAT / CFNAM_CAP_SYS_HEAT / CFTYP_CAP_SYS_HEAT` : capacity of the heating system (W.m$^{-2}$)

* :code:`XUNIF_CAP_SYS_RAT / CFNAM_CAP_SYS_RAT / CFTYP_CAP_SYS_RAT` : rated capacity of the cooling system (W.m$^{-2}$)

* :code:`XUNIF_T_ADP / CFNAM_T_ADP / CFTYP_T_ADP` : Apparatus dewpoint temperature of the cooling coil (K)

* :code:`XUNIF_M_SYS_RAT / CFNAM_M_SYS_RAT / CFTYP_M_SYS_RAT` : rated HVAC mass flow rate (kg.s$^{-1}$.m$^{-2}$)

* :code:`XUNIF_COP_RAT / CFNAM_COP_RAT / CFTYP_COP_RAT` : rated COP of the cooling system (1)

* :code:`XUNIF_COP_DCS / CFNAM_COP_DCS / CFTYP_COP_DCS` : rated COP of the district cooling system (1)

* :code:`XUNIF_T_SIZE_MAX / CFNAM_T_SIZE_MAX / CFTYP_T_SIZE_MAX` : Temperature for capacity of the cooling system (K)

* :code:`XUNIF_T_SIZE_MIN / CFNAM_T_SIZE_MIN / CFTYP_T_SIZE_MIN` : Temperature for capacity of the heating system (K)

* :code:`XUNIF_ISMECH / CFNAM_ISMECH / CFTYP_ISMECH` : control variable for presence of mechanical ventilation (0=no mechanical ventilation / 1=mechanical ventilation)

* :code:`XUNIF_MECHRATE / CFNAM_MECHRATE / CFTYP_MECHRATE` : air exchange due to mechanical ventilation (vol/h). Replace old key XUNIF_V_VENT. 0=

* :code:`XUNIF_SHADEARCHI / CFNAM_SHADEARCHI / CFTYP_SHADEARCHI` : presence of shading devices. 0=no / 1=adjustable / 2=permanent

* :code:`XUNIF_NATVENT / CFNAM_NATVENT / CFTYP_NATVENT` : Control variable for ventilation for up to 9 behaviours in building. 0=No ventilation / 1=Manual ventilation / 2=Automatic ventilation

* :code:`XUNIF_FRACOMP / CFNAM_FRACOMP / CFTYP_FRACOMP` : fractions of up to 9 tiles of building use/human behaviour. Sum of the fractions must equal 1.

* :code:`XUNIF_RESIDENTIAL / CFNAM_RESIDENTIAL / CFTYP_RESIDENTIAL` : residential fractions (only used for solar panel)

* :code:`XUNIF_TDESV / CFNAM_TDESV / CFTYP_TDESV` : Design temperature for ventilation. Indoor air temperature, people or automatic ventilation try to achieve by opening/closing of windows (K)

* :code:`XUNIF_WIN_SW_MAX / CFNAM_WIN_SW_MAX / CFTYP_WIN_SW_MAX` : threshold for shortwave radiation received by walls used for shading calculations (W/m$^{2}$)

* :code:`XUNIF_FOPEN / CFNAM_FOPEN / CFTYP_FOPEN` : maximum fraction of windows opened in case ventilation is made
