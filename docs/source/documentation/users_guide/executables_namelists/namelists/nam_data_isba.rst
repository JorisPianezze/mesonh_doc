* :code:`XUNIF_VEGTYPE / CFNAM_VEGTYPE / CFTYP_VEGTYPE` : fractions of each vegetation types

* :code:`XUNIF_RSMIN / CFNAM_RSMIN / CFTYP_RSMIN` : minimal stomatal resistance (s/m)

* :code:`XUNIF_GAMMA / CFNAM_GAMMA / CFTYP_GAMMA` : coefficient used in the computation of RSMIN (-)

* :code:`XUNIF_WRMAX_CF / CFNAM_WRMAX_CF / CFTYP_WRMAX_CF` : coefficient for maximum interception water storage capacity (-)

* :code:`XUNIF_RGL / CFNAM_RGL / CFTYP_RGL` : maximum solar radiation available for photosynthesis (W/m$^{2}$)

* :code:`XUNIF_CV / CFNAM_CV / CFTYP_CV` : vegetation thermal inertia coefficient (K m$^{2}$/J)

* :code:`XUNIF_Z0_O_Z0H / CFNAM_Z0_O_Z0H / CFTYP_Z0_O_Z0H` : ratio of surface roughness lengths (-)

* :code:`XUNIF_SEED_M / CFNAM_SEED_M / CFTYP_SEED_M` : month of seeding

* :code:`XUNIF_SEED_D / CFNAM_SEED_D / CFTYP_SEED_D` : day of seeding

* :code:`XUNIF_REAP_M / CFNAM_REAP_M / CFTYP_REAP_M` : month of reaping

* :code:`XUNIF_REAP_D / CFNAM_REAP_D / CFTYP_REAP_D` : day of reaping

* :code:`XUNIF_SEED_S2_M / CFNAM_SEED_S2_M / CFTYP_SEED_S2_M` : month for a second season of seeding

* :code:`XUNIF_SEED_S2_D / CFNAM_SEED_S2_D / CFTYP_SEED_S2_D` : day for a second season of seeding

* :code:`XUNIF_REAP_S2_M / CFNAM_REAP_S2_M / CFTYP_REAP_S2_M` : month for a second season of reaping

* :code:`XUNIF_REAP_S2_D / CFNAM_REAP_S2_D / CFTYP_REAP_S2_D` : day for a second season of reaping

* :code:`XUNIF_REAP_S3_M / CFNAM_REAP_S3_M / CFTYP_REAP_S3_M` : month for a third season of reaping

* :code:`XUNIF_REAP_S3_D / CFNAM_REAP_S3_D / CFTYP_REAP_S3_D` : day for a third season of reaping

* :code:`XUNIF_IRRIGTYPE / CFNAM_IRRIGTYPE / CFTYP_IRRIGTYPE` : irrigation type when LIRRIGMODE or LECOSG are activated. 0 for none, 1 for sprinkling, 2 for dripping and 3 for flooding. By default an irrigated vegetation type is 1 (sprinkler) and the others 0.

* :code:`XUNIF_IRRIGFRAC / CFNAM_IRRIGFRAC / CFTYP_IRRIGFRAC` : if LECOSG and LIRRIGMODE are activated, this key indicates the irrigation fraction [0-1] for each vegetation type (but only the vegetation types indicated in NUNIF_VEG_IRR_USE will be irrigated).

* :code:`XUNIF_IRRIGFREQ / CFNAM_IRRIGFREQ / CFTYP_IRRIGFREQ` : if LIRRIGMODE, keys to indicate the minimum time (in s) between two irrigation triggers. By default it is defined with XUNIF_IRRIGFREQ_CTYPE: values for the 3 types of irrigation, respectively sprinkling, dripping and flooding.

* :code:`XUNIF_IRRIGTIME / CFNAM_IRRIGTIME / CFTYP_IRRIGTIME` : if LIRRIGMODE, keys to indicate the duration of irrigation (in s).

* :code:`NTIME` : time dimension for ISBA parameters. 1=a single value for the whole year / 2=two values from January to June, and from July to December / 12=monthly parameters / 36=parameters updated each 10 days

* :code:`XUNIF_VEG / CFNAM_VEG / CFTYP_VEG` : fraction of vegetation for each vegetation types (-)

* :code:`XUNIF_LAI / CFNAM_LAI / CFTYP_LAI` : leaf area index (m$^{2}$/m$^{2}$)

* :code:`XUNIF_Z0 / CFNAM_Z0 / CFTYP_Z0` : roughness length (m)

* :code:`XUNIF_EMIS / CFNAM_EMIS / CFTYP_EMIS` : emissivity (-)

* :code:`XUNIF_ALBNIR_VEG / CFNAM_ALBNIR_VEG / CFTYP_ALBNIR_VEG` : vegetation near-infra-red albedo (-)

* :code:`XUNIF_ALBVIS_VEG / CFNAM_ALBVIS_VEG / CFTYP_ALBVIS_VEG` : vegetation visible albedo (-)

* :code:`XUNIF_ALBUV_VEG / CFNAM_ALBUV_VEG / CFTYP_ALBUV_VEG` : vegetation UV albedo(-)

* :code:`XUNIF_ALBNIR_SOIL / CFNAM_ALBNIR_SOIL / CFTYP_ALBNIR_SOIL` : soil near-infra-red albedo (-)

* :code:`XUNIF_ALBVIS_SOIL / CFNAM_ALBVIS_SOIL / CFTYP_ALBVIS_SOIL` : soil visible albedo (-)

* :code:`XUNIF_ALBUV_SOIL / CFNAM_ALBUV_SOIL / CFTYP_ALBUV_SOIL` : soil UV albedo (-)

* :code:`XUNIF_IRRIG / CFNAM_IRRIG / CFTYP_IRRIG` : flag for irrigation

* :code:`XUNIF_GNDLITTER` : litter layer thickness (m)

* :code:`XUNIF_Z0LITTER` : sub-forest canopy litter layer roughness (m)

* :code:`XUNIF_WATSUP / CFNAM_WATSUP / CFTYP_WATSUP` : water supply during irrigation process (mm)

* :code:`XUNIF_F2THRESHOLD / CFNAM_F2THRESHOLD / CFTYP_F2THRESHOLD` : if LIRRIGMODE, keys to indicate the threshold [0-1] for irrigation triggering. By default the value given by XTHRESHOLD in the namelist NAM_AGRI is used, but the value can be overwritten here.

* :code:`XUNIF_DG / CFNAM_DG / CFTYP_DG` : soil layer thickness (m)

* :code:`XUNIF_ROOTFRAC / CFNAM_ROOTFRAC / CFTYP_ROOTFRAC` : root fraction (-)

* :code:`XUNIF_ROOT_DEPTH / CFNAM_ROOT_DEPTH / CFTYP_ROOT_DEPTH` : root depth (-)

* :code:`XUNIF_GROUND_DEPTH / CFNAM_GROUND_DEPTH / CFTYP_GROUND_DEPTH` : ground depth for hydrology (-)

* :code:`XUNIF_ROOT_EXTINCTION / CFNAM_ROOT_EXTINCTION / CFTYP_ROOT_EXTINCTION` : root extinction percentage(-)

* :code:`XUNIF_ROOT_LIN / CFNAM_ROOT_LIN / CFTYP_ROOT_LIN` : root linear parameter (-)

* :code:`XUNIF_GMES / CFNAM_GMES / CFTYP_GMES` : mesophyll conductance (m/s$^{-1}$)

* :code:`XUNIF_BSLAI / CFNAM_BSLAI / CFTYP_BSLAI` : ratio d(biomass)/d(lai) (kg/m$^{2}$)

* :code:`XUNIF_LAIMIN / CFNAM_LAIMIN / CFTYP_LAIMIN` : minimum LAI (m$^{2}$/m$^{2}$)

* :code:`XUNIF_SEFOLD / CFNAM_SEFOLD / CFTYP_SEFOLD` : e-folding time for senescence (s)

* :code:`XUNIF_GC / CFNAM_GC / CFTYP_GC` : cuticular conductance (m/s)

* :code:`XUNIF_DMAX / CFNAM_DMAX / CFTYP_DMAX` : maximum air saturation deficit  (kg/kg)

* :code:`XUNIF_F2I / CFNAM_F2I / CFTYP_F2I` : critical normilized soil water content for stress parameterization (-)
