NAM_ECOCLIMAP2
--------------

.. csv-table:: NAM_ECOCLIMAP2 content 
   :header: "Fortran name", "Fortran type", "Default value"
   :widths: 30, 30, 30

   "LCLIM_LAI", "LOGICAL", "T"
   "YIRRIG", "CHARACTER(LEN=28)", "' '"

* :code:`LCLIM_LAI` : if T, climatological LAI is computed otherwise, the LAI corresponding to current year (if between 2002 and 2006) is used.

* :code:`YIRRIG` : irrigation file name
